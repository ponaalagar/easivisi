What You Need

  • Images ZIP: JPEG, PNG or other image formats
  • Labels ZIP: YOLO format .txt files (optional)
  • Matching Names: img001.jpg ↔ img001.txt

YOLO Label Format

Each line in .txt file:

class_id x_center y_center width height

All coordinates normalized to [0, 1]

Example: 0 0.5 0.5 0.3 0.4

What Happens

  1. System extracts and validates ZIP files
  2. Images matched with labels by filename
  3. Labels validated for correct YOLO format
  4. Files imported to dataset
  5. Detailed report shown with any errors
